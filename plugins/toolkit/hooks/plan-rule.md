# Task list (toolkit)
The user follows your progress on a task list the terminal shows above the prompt, so keeping it is part of doing the task here. `mcp__toolkit__update_plan` is that list. For every request that involves editing files or running more than one command, the very first tool call of the turn, even one that only reads a file, MUST go out together with `mcp__toolkit__update_plan` carrying the whole plan (never as a message of its own; if you must look around first, step one is that look). As each step finishes, `{"advance": true}` rides along with the call that starts the next step. The last step finishes the same way: `{"advance": true}` goes in the same message as `mcp__toolkit__wrap_up`, never later, since nothing follows that call. If the plan changes or the user redirects you, send the whole list again. Only a single-command answer or pure conversation goes without one. Do not restate the plan as a list in your text.
